# MiniMind Datasets

将所有下载的数据集文件放置到当前目录.

Place the downloaded dataset file in the current directory.

```text
agent_rl.jsonl           # 强化学习/智能体数据
agent_rl_math.jsonl      # 数学领域强化学习数据
dpo.jsonl                # DPO 对齐训练数据（大模型偏好优化）
lora_identity.jsonl      # LoRA 身份/角色定制数据
lora_medical.jsonl       # LoRA 医疗领域数据
pretrain_t2t.jsonl       # 【最大】预训练数据（文本到文本，8GB 多）
pretrain_t2t_mini.jsonl  # 预训练小样本集
rlaif.jsonl              # AI 反馈强化学习数据
sft_t2t.jsonl            # 【第二大】监督微调数据（文本到文本，14GB！）
sft_t2t_mini.jsonl       # 微调小样本集
```
